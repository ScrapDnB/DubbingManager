**Dubbing Manager** — настольное приложение для подготовки проектов озвучивания.
Оно связывает исходный сценарий, рабочий текст, персонажей, актёров, таймкоды и
видео: от импорта субтитров до телесуфлёра и проекта Reaper для записи.

Программа помогает режиссёру распределить роли, актёру получить свой текст,
звукорежиссёру подготовить сессию, а координатору оценить объём работы по сериям
и всему проекту. Основная работа с проектом выполняется локально; интернет
нужен для загрузки релизов и проверки обновлений.

![Dubbing Manager 2.0.0: актёры, персонажи и таймлайн серии](resources/screenshots/main-window-2.0.png)

*Главное окно на macOS. Демонстрационный проект «Северный маяк» использует
вымышленные имена, роли и реплики.*

## Что нового в 2.0

- **Интерфейс Qt Quick/QML.** Переработанное рабочее пространство, нативная
  панель инструментов macOS, адаптивная компоновка и настройки таблиц.
- **Рабочий текст внутри `.dub`.** Исходные строки и правки сохраняются в
  проекте; правила объединения реплик можно менять, сохраняя внесённые правки.
- **Таймлайн серии.** Реплики на временной шкале, цвета актёров и переход к
  персонажам для проверки кастинга и распределения нагрузки.
- **Телесуфлёр.** Плавная прокрутка по таймкодам, постраничный режим, зеркальное
  отображение, плавающий контроллер и синхронизация с Reaper по OSC или Nuendo по MIDI.
- **Аудиокниги.** Импорт PDF, DOCX, EPUB и TXT, редактор глав и ролей,
  проверка разметки, словарь произношений, суфлёр с отметками перезаписи и экспорт PDF.
- **Монтажные листы.** Настраиваемые макеты, профили оформления, визуальный
  конструктор шаблонов и предпросмотр с редактированием рабочего текста.
- **Сохранность проекта.** Undo/redo для поддерживаемых операций, атомарная
  запись, резервные копии и проверка структуры файлов.
- **Перенос проектов.** Относительные пути, диагностика связанных материалов
  и перепривязка исходников и видео после перемещения.
- **Доработки стабильного релиза.** Поиск актёров по нескольким частям имени,
  одинаковая обработка «е» и «ё», сохранение прокрутки предпросмотра при
  обновлении и защита текста от изменений при простой потере фокуса.

Подробности выпуска: [заметки к 2.1.0](RELEASE_NOTES.md).

## Скачать и установить

Готовые сборки находятся в [релизе 2.1.0](https://github.com/ScrapDnB/DubbingManager/releases/tag/v2.1.0).
Python и отдельная установка Qt для них не требуются. Интерфейс версии 2.1.0
доступен на русском языке.

| Платформа | Файл | Установка |
| --- | --- | --- |
| macOS 13 и новее | `Dubbing_Manager_macOS.dmg` | Откройте образ и перенесите `Dubbing Manager.app` в `Applications` |
| Windows | `Dubbing_Manager_Windows.zip` | Полностью распакуйте архив и запустите `Dubbing Manager.exe` из папки приложения |

### macOS

После установки запустите приложение из `Applications`. Проекты `.dub` и
резервные копии `.dub_backup` можно открывать двойным кликом.

Сборка использует ad-hoc подпись. Если macOS блокирует первый запуск, проверьте,
что файл скачан из этого репозитория, и разрешите открытие в системных настройках
**Конфиденциальность и безопасность**.

### Windows

Храните `.exe` вместе с остальным содержимым распакованной папки: сборка
использует поставляемые рядом библиотеки и ресурсы.

Для открытия проектов двойным кликом выполните в PowerShell из папки приложения:

```powershell
.\Register_DUB_File_Association.ps1
```

Скрипт регистрирует `.dub` и `.dub_backup` для текущего пользователя. Для удаления
ассоциаций используйте параметр `-Unregister`.

Обновления можно проверить в окне **О программе**. Все опубликованные версии
доступны в [GitHub Releases](https://github.com/ScrapDnB/DubbingManager/releases).

## Быстрый старт

### Дубляж или закадровое озвучивание

1. Создайте новый проект и задайте его название в настройках проекта.
2. Сохраните проект как `.dub` в рабочую папку.
3. Импортируйте сценарий `.ass`, `.srt`, `.docx` или таблицу `.xls`, `.xlsx`, `.csv`.
   Для DOCX и таблиц сопоставьте колонки с персонажами, таймкодами и текстом,
   проверьте первую строку данных и предпросмотр.
4. Добавьте актёров в проект вручную или перенесите из глобальной базы.
5. Назначьте актёров персонажам. Выберите область назначения: весь проект или
   только текущая серия.
6. Проверьте неназначенные роли, объём текста и таймлайн; при необходимости
   привяжите видео к серии.
7. Откройте **Монтажный лист**, настройте макет и экспортируйте материалы.
   Для записи используйте **Телесуфлёр** или **Экспорт в Reaper**.

Для следующей серии импортируйте новый сценарий в тот же проект: общие назначения
ролей будут использоваться повторно, а исключения можно задать на уровне серии.

### Аудиокнига

1. Создайте новый проект, затем откройте **Аудиокнига**. Сохраните проект после импорта книги.
2. Нажмите **Импорт книги** и выберите PDF с текстовым слоем, DOCX, EPUB или TXT.
3. Проверьте найденные главы в **Структуре глав** и исправьте границы и названия.
4. Добавьте актёров, подготовьте роли и назначьте часто используемые роли слотам 1–9.
5. Выделяйте фрагменты текста и применяйте нужную роль; проверьте результат
   разметки и распределение текста между исполнителями.
6. Откройте **Проверку**: переходите к замечаниям, назначайте роль и актёра либо
   пропускайте допустимые случаи. Пометьте проверенные главы как готовые.
7. Добавьте ударения и подсказки в **Словарь произношений**. Через **Запись**
   откройте главу в телесуфлёре. F8 отмечает текущий фрагмент на перезапись;
   список можно выгрузить в CSV. После закрытия сохраняется позиция чтения.
8. Через **Экспорт PDF** выберите главы, общий файл или отдельные файлы и макет
   для чтения либо студийной записи.

Изменения текста автоматически попадают в проект. После первого сохранения `.dub`
включённое **Автосохранение** также записывает проект на диск после паузы в работе.
Cmd+S / Ctrl+S сохраняет сразу. Аудио записывается во внешней DAW (Reaper или Nuendo); отметки
перезаписи содержат фрагмент текста, а не таймкод фактической записи.

PDF-сканы без текстового слоя требуют предварительного OCR. Распознавание
изображений страниц в Dubbing Manager не входит.

## Возможности

### Сценарии и серии

- Импорт ASS, SRT, табличных DOCX, XLS, XLSX и CSV с настройкой колонок.
- Выбор листов Excel: каждый выбранный лист становится отдельной серией со
  своими колонками, первой строкой данных и названием; пакет отменяется одним Undo.
- Кодировки и разделители CSV, объединённые ячейки Excel и Excel-время.
- Несколько серий в проекте, переименование и удаление серий.
- Объединение исходных строк в рабочие реплики по правилам импорта и тайминга.
- Правки рабочего текста без обязательной перезаписи исходного сценария.
- Поиск по проекту с переходом к найденной серии и персонажу.
- Видео серии и просмотр реплик по таймкоду.
- Быстрый конвертер ASS/SRT для подготовки листов без полноценного проекта.
- Перетаскивание проектов и сценариев в главное окно.

### Главное окно: кастинг и текст

Переключатель «Кастинг / Текст» расположен рядом с инструментами. Раздел при
запуске выбирается в **Настройки программы → Главный экран**; по умолчанию
открывается «Кастинг». Переключение разделов не меняет стартовый выбор. В кастинге
справа от актёров находится список серий, а справа от таблицы — карточка
персонажа с назначениями, статистикой и переходом к его репликам. На узком
окне серии и карточка открываются выдвижными панелями.

Там же можно выбрать светлую, тёмную или системную тему. По умолчанию тема
следует настройкам ОС; изменения применяются ко всем окнам после сохранения.

Кнопка «Аудиокнига» на верхней панели доступна в новом пустом проекте и
в проекте аудиокниги. Для проекта сериала она неактивна.

В «Тексте» можно искать и фильтровать реплики, редактировать текст, персонажа
и таймкоды и просматривать видео. Щелчок по сегменту таймлайна или его шкале
выбирает реплику и перематывает видео в указанную точку. Корректная правка
применяется при переходе и сохранении; неверный таймкод блокирует переход,
пока правка не исправлена или отменена. Поддерживаются undo/redo.

### Актёры и распределение ролей

- Проектная и глобальная базы актёров, цветовая маркировка и пол.
- Поиск в глобальной базе по частям имени, независимо от регистра и «е»/«ё».
- Один или несколько актёров на роль, общие назначения и исключения по сериям.
- Массовое назначение и перенос кастинга между проектами.
- Фильтры по актёру, персонажу и неназначенным ролям.
- Статистика исходных строк, сформированных реплик и слов; просмотр роли по сериям.
- Настройка порядка, ширины и видимости колонок основной таблицы.

### Телесуфлёр и запись

- Несколько сценарных макетов и фильтрация по исполнителям.
- Настройка шрифтов, размеров, цветов, таймкодов и подсветки.
- Ручная навигация, плавная прокрутка и постраничный режим.
- Зеркальное отображение для аппаратного телесуфлёра.
- Плавающее окно управления и работа с отдельным экраном.
- Приём позиции и состояния воспроизведения Reaper по OSC, отправка навигации
  при включённой исходящей синхронизации.
- Настраиваемое смещение исходящих переходов отдельно для Reaper и Nuendo.
- Nuendo: приём MIDI Timecode (MTC), отправка переходов MIDI Machine Control (MMC).

### Монтажные листы и отчёты

- Табличные и сценарные макеты с живым предпросмотром.
- Настройка колонок, оформления, цветовой маркировки и формата таймкода.
- Редактирование текста в предпросмотре с сохранением правок в рабочем тексте.
- Визуальный конструктор и библиотека шаблонов.
- Экспорт одной серии или всего проекта в HTML, XLSX, DOCX и PDF.
- Отчёт по серии, сводка проекта и данные для переноса в Google Sheets.
- Экспорт Reaper `.rpp` и CSV-маркеров.

### Аудиокниги

- Импорт PDF, DOCX, EPUB и TXT с первоначальным выделением глав.
- Рабочее окно с нативными элементами macOS и Windows 11, поиском по книге,
  редактором структуры глав и оценкой длительности чтения.
- Разметка выделенных фрагментов ролями, палитра актёров, быстрые слоты 1–9,
  отмена и повтор правок текста. Количество ролей не ограничено девятью слотами.
- Проверка диалогов и назначений с переходом к фрагменту, исправлением и
  состоянием готовности каждой главы.
- Словарь произношений, сохранение позиции в суфлёре, отметки перезаписи по F8
  и экспорт списка в CSV.
- Сохранение текста, кастинга и рабочих отметок в `.dub`, автосохранение на диск.
- PDF по выбранным главам, единым документом или отдельными файлами.

## Работа с Reaper

### Подготовка сессии

Откройте **Экспорт в Reaper**, проверьте параметры и сохраните `.rpp`. В зависимости
от выбранных настроек сессия содержит треки актёров, регионы реплик и связанное
видео. Маркеры можно сохранить отдельно в `.csv`. Экспорт доступен для текущей
серии и серий проекта.

### Синхронизация телесуфлёра с Reaper по OSC

Для работы на одном компьютере используются следующие значения по умолчанию:

| Направление | Настройка Dubbing Manager | Настройка Reaper |
| --- | --- | --- |
| Reaper → Dubbing Manager | Принимает: `8000` | Device port: `8000` |
| Dubbing Manager → Reaper | Отправляет: `9000` | Local listen port: `9000` |
| Адрес Reaper | `127.0.0.1` | Device IP: `127.0.0.1` |

1. В Reaper откройте **Options → Preferences → Control/OSC/Web**.
2. Нажмите **Add** и выберите **OSC (Open Sound Control)**.
3. Укажите IP и порты из таблицы; оставьте `Default.ReaperOSC` в Pattern config.
4. В настройках Dubbing Manager откройте раздел **Синхронизация с DAW**, выберите **Reaper · OSC** и включите синхронизацию.
5. Включите приём синхронизации; отправку включайте, если навигация телесуфлёра
   должна перемещать курсор Reaper.

### Синхронизация телесуфлёра с Nuendo по MIDI

В **Настройки → Синхронизация с DAW** выберите **Nuendo · MIDI**. Одновременно
работает только выбранная DAW; OSC-порты и смещение Reaper сохраняются.
Включите синхронизацию, задайте частоту кадров из **Project Setup** Nuendo и
начало таймкода проекта (например, `01:00:00`, если первая секунда сценария
соответствует таймкоду 01:00:00 в Nuendo). Смещение исходящих переходов
настраивается отдельно в телесуфлёре и не меняет входящий таймкод.

**macOS:** выберите «Создать порт Dubbing Manager» для MTC и MMC, сохраните
настройки и откройте телесуфлёр. Приложение создаст порты **Dubbing Manager MTC**
и **Dubbing Manager MMC**. Выход MMC открывается при включении
«DAW следует за навигацией» в телесуфлёре. Также можно использовать два
существующих порта IAC Driver или аппаратного MIDI-интерфейса.

**Windows:** создайте два разных порта в
[loopMIDI](https://www.tobias-erichsen.de/software/loopmidi.html):
**Nuendo to Dubbing Manager** и **Dubbing Manager to Nuendo**. Оставьте loopMIDI
работать в области уведомлений: его порты существуют только пока оно запущено.
В Dubbing Manager выберите первый порт для приёма MTC, второй для отправки MMC.
Кнопка «Обновить MIDI-порты» обновляет список после создания портов. Вместо
loopMIDI можно использовать аппаратные MIDI-соединения. RtMidi использует
системный MIDI API Windows и не создаёт виртуальные порты самостоятельно.

| Направление | Dubbing Manager | Nuendo |
| --- | --- | --- |
| Nuendo → телесуфлёр | Приём таймкода MTC | MIDI Timecode Destinations: этот же порт |
| Телесуфлёр → Nuendo | Отправка переходов MMC | Machine Control Input / MIDI Input: этот же порт |

В Nuendo откройте **Transport → Project Synchronization Setup**:

1. **Sources:** оставьте **Internal Timecode**, выключите **Activate External Sync**.
   Nuendo воспроизводит собственный проект и передаёт его позицию телесуфлёру.
2. **Destinations:** выберите выход MTC в Dubbing Manager, включите
   **MIDI Timecode Follows Project Time**, установите **Timecode Offset** в 0.
3. **Machine Control:** выберите вход **MIDI Machine Control**, назначьте вход
   MMC из Dubbing Manager. Если нужен порт ответов MMC, назначьте противоположный
   порт, ведущий в Dubbing Manager. **MMC Device ID** должен совпадать;
   значение 127 в Dubbing Manager посылает команды всем устройствам.
4. В **Studio Setup → MIDI Port Setup** исключите эти порты из **All MIDI Inputs**,
   чтобы служебный таймкод не записывался на музыкальные треки.

В телесуфлёре доступны прежние режимы: следование за DAW, следование только
во время Play, обратная навигация по репликам, плавная/постраничная прокрутка,
смещение исходящих переходов и переподключение без сброса позиции.

MTC Full Frame задаёт позицию при остановке и перемотке; Quarter Frame передаёт
текущую позицию во время воспроизведения. Декодер учитывает задержку MTC в два
кадра, обратное направление, 29.97 Drop Frame и дробные частоты 23.976/29.97.
Для дробных частот настройка проекта обязательна: флаг MTC сам по себе не
отличает 23.976 от 24 и 29.97 Non-Drop от 30. При несовпадении распознаваемой
частоты кадров приложение сообщает об ошибке.

После прекращения Quarter Frame воспроизведение считается остановленным через
0.3 секунды. MTC не передаёт отдельный признак соединения: в режиме Stop тишина
не позволяет отличить паузу от закрытой Nuendo. Поэтому состояние после приёма
таймкода остаётся «MIDI активен»; исчезновение выбранного системного порта
показывается как ошибка. Если Nuendo не передаёт Full Frame в режиме Stop,
следование за ручными переходами в этом режиме невозможно без дополнительного
источника позиции. Нужна проверка с используемой версией Nuendo.

При разработке установите зависимости из `requirements.txt`; сборка включает
`python-rtmidi` и его нативный модуль. При сборке MIDI-библиотеки из исходников
для macOS соблюдайте `MACOSX_DEPLOYMENT_TARGET` выбранного выпуска приложения.

Настройки Nuendo описаны в документации Steinberg:
[MTC Destinations](https://www.steinberg.help/r/nuendo/15.0/en/cubase_nuendo/topics/synchronization/synchronization_setup_sync_outputs_r.html),
[Machine Control](https://www.steinberg.help/r/nuendo/15.0/en/cubase_nuendo/topics/synchronization/synchronization_setup_machine_control_r.html).
6. Откройте телесуфлёр и проверьте движение по таймкоду при воспроизведении.

Порты можно изменить, сохранив соответствие в обеих программах. Если соединения
нет, проверьте адрес, занятость UDP-портов и разрешения межсетевого экрана.

## Форматы и хранение проекта

| Назначение | Форматы |
| --- | --- |
| Входные сценарии | `.ass`, `.srt`, табличный `.docx`, `.xls`, `.xlsx`, `.csv` |
| Входная книга | `.pdf` с текстовым слоем |
| Проект | `.dub` |
| Резервная копия | `.dub_backup` |
| Импорт старого проекта | legacy `.json`, старые `.dub` |
| Связанное видео | `.mp4`, `.mkv`, `.avi`, `.mov`, `.m4v`, `.wmv` |
| Монтажные листы | `.html`, `.xlsx`, `.docx`, `.pdf` |
| Размеченная аудиокнига | `.pdf` |
| Сессия и маркеры Reaper | `.rpp`, `.csv` |

Проект 2.0 хранит кастинг, настройки, исходные строки и правки рабочего текста,
а для аудиокниги — структуру глав и размеченный текст. Видео остаётся внешним
файлом; `.dub` не является архивом всех медиафайлов.

Рабочие тексты, уже сохранённые внутри проекта, доступны без исходного сценария.
Для повторного импорта и других операций с исходниками сохраните оригинальные
ASS/SRT/DOCX/XLS/XLSX/CSV/PDF. После перемещения папки откройте **Файлы проекта**, проверьте
состояние связей и перепривяжите отсутствующие материалы.

### Импорт DOCX и таблиц

Откройте **Импорт серии → Сценарий DOCX** или **Таблица XLS / XLSX / CSV**;
файл также можно перетащить в главное окно. Назначьте колонки и сравните вкладки
**Реплики после импорта** и **Исходные колонки**. Колонка текста обязательна;
тайминг можно задать диапазоном либо отдельными началом и концом.

Для Excel отметьте нужные листы, затем нажмите на каждый лист, чтобы проверить
его настройки и изменить название серии. Пустые листы не импортируются,
скрытые изначально не выбраны. Для DOCX можно импортировать текущую таблицу
или собрать все таблицы в одну серию с общим назначением колонок.

Галочка **Игнорировать заголовок таблицы** пропускает начальную строку
таблицы; строки выше выбранной начальной строки также исключаются. Состояние
галочки сохраняется отдельно для каждого листа или таблицы DOCX. Кнопка
**Применить колонки ко всем сериям** копирует назначение колонок и состояние
галочки пропуска заголовка текущего листа во все непустые листы книги, включая
неотмеченные. Названия серий и начальные строки таблиц остаются индивидуальными.
Если на листе нет нужной
колонки, исправьте его настройки или снимите отметку перед импортом. В CSV
кодировка и разделитель определяются автоматически, при необходимости их
можно изменить вручную. Числовой тайминг читается в секундах; для чисел Excel
без форматирования времени выберите **Доли суток Excel**. Для таймкода с кадрами
укажите FPS. Строки без текста пропускаются; ошибки тайминга таблиц показываются
до импорта и требуют исправления настроек или исходника.

Одна строка становится одной репликой без объединения соседних строк. Рабочий
текст и настройки выбранного листа сохраняются внутри `.dub`; восстановление
из исходника использует именно этот лист и его настройки. XLSX читает сохранённые
результаты формул, поэтому перед импортом пересчитайте и сохраните книгу в Excel
или другом табличном редакторе.

## Переход с 1.7 на 2.0

Версия приложения — **2.1.0**, версия формата проекта — **2.0**.

1. Сделайте копию проекта 1.7 и связанных исходников.
2. Откройте старый `.dub` или `.json` в Dubbing Manager 2.1.0.
3. Проверьте серии, назначения актёров, рабочий текст и пути к видео.
4. Сохраните результат под новым именем `.dub`, оставив исходную копию для 1.7.

Старые субтитровые проекты сохраняют прежнюю модель текста и номер формата.
Для перехода на построчную модель откройте **Файлы проекта → Конвертировать в новый
формат**; для конвертации нужны найденные ASS всех серий. Проверьте результат
перед сохранением: до сохранения операцию можно отменить.

Проекты, сохранённые в формате 2.0, не предназначены для открытия в 1.x.
Предварительный экспериментальный формат аудиокниг не поддерживается: для таких
файлов потребуется повторный импорт PDF.

Исходники версии 1.7.1 сохранены в ветке
[`legacy/1.7`](https://github.com/ScrapDnB/DubbingManager/tree/legacy/1.7), а готовая
сборка — в [релизе 1.7.1](https://github.com/ScrapDnB/DubbingManager/releases/tag/v1.7.1).

## Сохранение и резервные копии

Ручное сохранение записывает проект атомарно. Автоматические резервные копии
содержат снимок проекта в `.dub_backup`; их параметры находятся в глобальных
настройках:

- включение резервных копий и интервал;
- папка рядом с проектом или отдельный абсолютный путь;
- максимальное количество сохраняемых копий.

Копии каждого сохранённого проекта лежат в отдельной подпапке, поэтому проекты
с похожими именами не участвуют в ротации копий друг друга. Относительную папку
с копиями можно переносить вместе с проектом. Старые стандартные автокопии и
копии перед восстановлением остаются доступны в списке; старые копии с другими
именами можно открыть как `.dub_backup`. Старые файлы не удаляются ротацией.

Используйте встроенный просмотр резервных копий для выбора и восстановления
нужного состояния. Видео и другие внешние материалы копируйте отдельно вместе
с рабочей папкой.

## Частые вопросы

**Почему DOCX не импортируется как сценарий?**

Импорт рассчитан на таблицы. Проверьте сопоставление колонок и наличие таймкодов,
имён персонажей и текста в выбранных столбцах.

**Почему в книге нет текста или неверно выделены главы?**

Проверьте наличие текстового слоя PDF. Для сканов сначала выполните OCR; границы
и названия глав можно исправить в редакторе структуры.

**Как исправить потерянные файлы после переноса проекта?**

Откройте **Файлы проекта** и задайте актуальные пути. Для переноса на другой
компьютер копируйте `.dub` вместе с исходниками и видео.

**Можно ли работать без Reaper?**

Да. Импорт, кастинг, отчёты, монтажные листы, аудиокниги и ручная навигация
телесуфлёра работают независимо от Reaper.

**Есть ли готовая сборка для Linux?**

Релизный workflow выпускает macOS и Windows. Запуск из исходников на другой
платформе зависит от доступности зависимостей и отдельно не проверяется в CI.

## Запуск из исходников

Windows-сборка использует **Python 3.14** и **PySide6 6.10.2**.
Для совместимости macOS-сборки с **macOS 13** используются **Python 3.13** и
**PySide6 6.9.3** из [requirements-macos13.txt](requirements-macos13.txt).
Обе сборки используют **PyInstaller 6.20.0**. Для обычного запуска из исходников
зависимости перечислены в [requirements.txt](requirements.txt); команды сборки
для macOS 13 приведены в [.github/BUILD.md](.github/BUILD.md#совместимость-с-macos-13).

```bash
git clone https://github.com/ScrapDnB/DubbingManager.git
cd DubbingManager
git checkout master
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python qml_main.py
```

В Windows после создания окружения:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python qml_main.py
```

Для воспроизведения именно релиза 2.1.0 выберите `git checkout v2.1.0` перед
установкой зависимостей. Для открытия конкретного проекта:

```bash
python qml_main.py /path/to/project.dub
```

### Проверки и сборка

```bash
python -m pytest -q
python scripts/lint_qml.py
python -m PyInstaller dubbing_manager.spec --clean
```

сервисы, формат проекта, совместимость, экспорт, QML backend, телесуфлёр и
межпроцессное открытие проектов.

Готовые артефакты собираются на соответствующей ОС. Подробности упаковки,
подписи macOS и публикации находятся в [.github/BUILD.md](.github/BUILD.md).
